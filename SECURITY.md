# Security and privacy

Do not report or attach private portrait images, model credentials, registry
files, or generated results containing personal data in public issues.

The pipeline processes local images and writes outputs under the project root.
Review `out/`, `out1/`, `out2/`, `out3/`, and `outfinal/` before sharing a
folder. These directories are ignored by Git by default.

If you discover a security issue, contact the maintainers privately. Replace
any placeholder maintainer contact before publishing the repository.
