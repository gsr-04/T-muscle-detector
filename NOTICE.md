# Third-party notices

This repository contains integration code for third-party body segmentation,
pose estimation, clothing segmentation, and edge-detection models.

The MIT licence at the repository root applies only to original source code in
this repository. It does **not** grant rights to model weights, training data,
or upstream project assets.

Before redistributing models or generated derivatives, verify and retain each
upstream project's licence and attribution requirements. This repository does
not bundle model weights, portrait images, datasets, or pretrained checkpoints.

Referenced model families include:

- MediaPipe Pose Landmarker
- RTMPose / MMPose
- Self-Correction for Human Parsing (SCHP)
- BiRefNet
- DexiNed

Consult the upstream repositories and model cards for their current terms.
